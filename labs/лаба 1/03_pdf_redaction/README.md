# Секрет закрасили — мы его прочитали

Скрипт создаёт PDF с вымышленным случайным кодом и закрывает его чёрным прямоугольником. Затем другой скрипт извлекает текст из этого же PDF.

## Установка и запуск
Windows 10/11, браузер с просмотром PDF. Для установки нужен интернет; Python и редактор кода заранее не нужны.

1. Распакуйте весь репозиторий из ZIP.
2. Запустите `setup.cmd`, дождитесь сообщения `Ready`.
3. Запустите `start.cmd`. Он создаст `data/document.pdf` и откроет его программой просмотра PDF.
4. Если Windows предложит выбрать программу, выберите Edge или Chrome. Можно открыть файл вручную, перетащив его в окно браузера.

Python и PyMuPDF устанавливаются автоматически, без администратора и изменения PATH. Подготовленный Python из задачи 1 используется повторно; иначе устанавливается отдельный. Если политика компьютера запрещает запуск, обратитесь к администратору.

## Опыт
1. Посмотрите PDF: под надписью **Access code** находится чёрная полоса. Код глазами не прочитать.
2. Не закрывая документ, запустите **extract.cmd**.
3. В открывшемся окне появится извлечённый текст, включая строку вида `DEMO-...`. Это и есть спрятанный код.
4. Сравните результат с PDF: на странице код всё ещё закрыт.

Каждый запуск `start.cmd` создаёт новый код и заменяет PDF. Перед повторным запуском закройте PDF в просмотрщике, чтобы он не мешал перезаписи.

## Почему сработало
В PDF сначала записан текст, затем поверх него нарисован прямоугольник. Рисунок закрывает буквы на экране, но не удаляет их из файла.
`extract_text.py` читает текст самого PDF. Он не знает код заранее и не получает его из отдельного файла.

## Реализация защиты: что изменить

### 1. Закройте PDF и откройте исходник
Закройте документ в просмотрщике. Откройте `create_pdf.py` через «Открыть с помощью» → «Блокнот».

### 2. Найдите строку с прямоугольником
Нажмите Ctrl+F и найдите:

```python
    page.draw_rect(secret_rect, color=(0, 0, 0), fill=(0, 0, 0), overlay=True)
```

### 3. Замените одну строку двумя
```python
    page.add_redact_annot(secret_rect, fill=(0, 0, 0))
    page.apply_redactions()
```

Перед каждой новой строкой оставьте **четыре пробела**.

Первая строка отмечает область для удаления содержимого. Вторая **применяет удаление**. Без второй строки содержимое ещё не удалено.

`secret_rect` — прямоугольная область, в которой находится код. Она определена строкой выше; её не меняйте. Параметр `fill=(0, 0, 0)` оставляет область чёрной.

Ниже в файле уже есть строка сохранения:

```python
    doc.save(OUT / "document.pdf", garbage=4, deflate=True)
```

Её менять не нужно: документ сохраняется заново с очисткой неиспользуемых объектов, а не дописывает изменения в старый файл.

### 4. Сохраните и повторите опыт
1. Нажмите Ctrl+S.
2. Запустите `start.cmd`: он заново создаст PDF по изменённому коду.
3. Посмотрите документ: чёрная полоса осталась.
4. Запустите `extract.cmd`: строки `DEMO-...` теперь быть не должно.
5. Должно появиться сообщение `No DEMO code found in the extracted text.`

В этом примере код существует только как текст в отмеченной области. Для произвольного документа одной проверки извлечённого текста недостаточно: сведения могут остаться в метаданных, вложениях, изображениях и других местах.
