# Покупка за одну монету

Учебный магазин: товар стоит 10 000 монет, на счету только 100. Все данные вымышленные, настоящих платежей нет. Сайт запускается только на этом компьютере.

## Установка и запуск
Windows 10/11, браузер Edge или Chrome. Python и Git не нужны. Для установки нужен интернет.
1. Распакуйте весь репозиторий из ZIP в доступную для записи папку.
2. В этой папке запустите `setup.cmd`. Он подготовит Python и зависимости. Дождитесь `Ready`.
3. Запустите `start.cmd`.
4. Откройте http://127.0.0.1:5051.
5. Для остановки нажмите Ctrl+C в окне сервера.

Python устанавливается без администратора и изменения PATH. Подготовленный Python из задачи 1 используется повторно; иначе установка выполняется автоматически. Если политика компьютера запрещает запуск, обратитесь к администратору. Если порт занят, остановите предыдущий экземпляр сайта.

## Опыт
1. Нажмите **«Сбросить опыт»**. Баланс — 100, заказов нет.
2. Нажмите **«Купить»**. Получите «Недостаточно монет».
3. Нажмите **F12** (или Ctrl+Shift+J), откройте вкладку **Console / Консоль**.
4. Для этого локального учебного сайта выполните следующий запрос. Прочитайте код: он отправляет серверу код товара и цену **1**. Не вставляйте в консоль непроверенный код с чужих сайтов.

```javascript
fetch("/buy", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ product_id: "robot", price: 1 })
}).then(response => response.json()).then(result => console.log(result.message))
```

Если браузер запрещает вставку в консоль, не отключайте его предупреждение: наберите этот короткий вариант вручную и нажмите Enter:

```javascript
fetch("/buy",{method:"POST",headers:{"Content-Type":"application/json"},body:'{"product_id":"robot","price":1}'}).then(r=>r.json()).then(console.log)
```

5. Дождитесь ответа «Куплено за 1 монет!».
6. Обновите страницу. Баланс — **99**, в сохранённых заказах — робот за **1** монету. Это не просто изменение надписи в браузере: сервер записал заказ в базу.

Для повторения нажмите **«Сбросить опыт»**. Заказы сохраняются после перезапуска сервера в `data/shop.sqlite3`.

## Почему сработало
Кнопка отправляет цену 10 000. Мы отправили тот же запрос, но с ценой 1. Сервер взял цену из сообщения покупателя, а не из своего каталога. Проверка положительного числа не помогает: единица тоже положительное число.

## Реализация защиты: что изменить

### 1. Остановите сайт
Нажмите Ctrl+C в окне сервера. Откройте `app.py` в Блокноте через «Открыть с помощью».

### 2. Найдите строку
Нажмите Ctrl+F и найдите:

```python
        price = data["price"]
```

### 3. Замените её целиком
```python
        price = PRODUCT["price"]
```

Сохраните восемь пробелов перед `price`. Остальной код менять не нужно.

`data` — сообщение покупателя, которое он может изменить. `PRODUCT` — каталог на сервере. Теперь сервер берёт цену из своего каталога. Код товара уже проверяется выше: в этом маленьком магазине продаётся только один товар.

### 4. Сохраните и проверьте
1. Нажмите Ctrl+S и снова запустите `start.cmd`.
2. Обновите страницу и нажмите **«Сбросить опыт»**.
3. Повторите запрос из консоли с ценой 1.
4. Ответ должен быть «Недостаточно монет».
5. Обновите страницу: баланс **100**, заказов нет.
6. Обычная кнопка «Купить» тоже должна отказать: настоящая цена превышает баланс.

Смена HTML, запрет редактирования поля и JavaScript-проверка не исправляют доверие сервера к цене клиента.
